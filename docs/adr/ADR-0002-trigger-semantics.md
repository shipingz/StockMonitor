# ADR-0002: 触发语义 — A型「上穿」触发 + MA60 口径1（包含当前K线）

- 状态：**已确认**
- 日期：2026-08-15（讨论确认）

## 背景

需要明确「15分钟K线收盘价超过MA60」的精确判定语义，以及同一股票同一天的推送频率边界。

## 触发语义选项

| 方案 | 行为 | 噪音量级 |
|---|---|---|
| A. 上穿触发 | 收盘价从 ≤MA60 变为 >MA60 时推送一次；持续在 MA60 上方不重复推送 | 低 |
| B. 高于就推 | 每根K线收盘时只要 >MA60 就推送 | 一只股票一天最多 16 条，全量满足时 50 只 × 16 = 800 条/天 |
| C. 回落再上穿 | 每次「上穿事件」都推（回落后重新上穿可再推） | 中 |

## MA60 计算口径选项

| 方案 | 定义 | 特征 |
|---|---|---|
| 口径1（含当前K线） | `MA60 = 最近60根收盘价的均值`，含刚收盘的这根 | 行情软件默认口径，信号稍滞后但平滑、可对照 |
| 口径2（不含当前K线） | 用前 60 根算 MA60，当前收盘价与之比较 | 更灵敏，但和行情软件显示对不上 |

## 决策

- 触发语义：**A型，上穿触发**。判定条件：当前K线收盘价 > MA60，且上一根K线收盘价 ≤ MA60。
  - 若连续多根K线在 MA60 上方，只推第一根（上穿那根）。
- MA60 口径：**口径1，包含当前K线**。
- 同一股票同一天的推送次数：由「上穿事件」自然约束——从下方上穿几次就推几次，但**正常情况下一天最多 1 次**（收盘价很难反复穿越 60 根均线）；若担心极端震荡行情，可在实现时加「同一股票同一交易日的推送上限」兜底，默认不设或设 3 次，待讨论。

### 实现说明（与 `main.py` `compute_ma_signal` 一致）

「上一根K线收盘价 ≤ MA60」中的 MA60 取**上一时刻的 MA60**（前 60 根，含上一根、不含当前K线）：
- `cur_ma  = mean(最近 60 根收盘价)`（含当前K线，口径1）
- `prev_ma = mean(前 60 根收盘价)`（含上一根、不含当前）
- 上穿 = `cur_close > cur_ma 且 prev_close <= prev_ma`

理由：若用同一个 `cur_ma` 与 `prev_close` 比较，当上一根已位于 MA 上方（`prev_close > prev_ma` 但 `prev_close <= cur_ma`）时会误判上穿；用各自时刻的 MA 值才符合「从下方穿越」的定义。

## 后果

- 推送量与真实信号一致，噪音可控。
- 「上穿」判定依赖相邻两根K线数据，判定逻辑完全可以在**单次抓取的K线序列内完成**（无需跨运行状态推断），这为 ADR-0005 的状态设计减负。
